# 🌟 JobHub

> A next-generation job board platform bridging the gap between top-tier talent and innovative companies.

JobHub is a modern, high-performance Angular application engineered to deliver a seamless experience for both job seekers and employers. With dedicated portals, intuitive dashboards, and dynamic data handling, it simplifies the entire recruitment lifecycle.

---

## 🚀 Core Features

### 👨‍💼 For Job Seekers
- **Smart Onboarding:** A dedicated step-by-step profile creation flow featuring avatar and resume uploads.
- **Intuitive Dashboard:** Real-time application tracking (Applied, Interviewing, Offer, Rejected).
- **Advanced Filtering:** Instantly sort and discover jobs by category, location, stipend, and work mode (Remote/Hybrid/Onsite).

### 🏢 For Employers
- **Company Portal:** A dedicated, secure workspace to manage the company's brand and listings.
- **Job Management:** Post, edit, and toggle active job listings seamlessly.
- **Applicant Tracking:** Review and manage incoming candidate applications through a clean, streamlined UI.

---

## 💻 Tech Stack

- **Framework:** Angular (Standalone Components)
- **Language:** TypeScript, HTML5
- **Styling:** Custom CSS (Utility-first, Tailwind-inspired architecture)
- **Forms & Data:** Angular Reactive Forms

## 🛠️ Quick Start Guide

Follow these steps to set up the development environment on your local machine.

### 1. Install Dependencies
Ensure you have Node.js and the Angular CLI installed. Open your terminal, navigate to the project folder, and run:

```bash
npm install

```

### 2. Launch the Development Server

Fire up the local environment by running:

```bash
npm start

```

Open your browser and navigate to `http://localhost:4200/`. The application will automatically reload if you change any of the source files.

---

## 📁 Project Structure Highlights

* `/src/app/home/` - Landing page, search interface, and primary job feed.
* `/src/app/Company/` - Complete employer ecosystem (Registration, Job Posting, Profile Settings).
* `/src/app/Job-seeker/` - Complete candidate ecosystem (Onboarding, Profile Setup, Dashboard).
